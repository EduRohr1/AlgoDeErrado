Conecte o Apify para buscar os dados automaticamente

  1. Crie uma conta grátis em apify.com.
  2. Copie seu token em Settings → API & Integrations.
  3. Cole no campo Token do Apify acima e clique em Atualizar dados agora. Leva de 1 a 3 minutos.

Depois disso, o site se atualiza sozinho sempre que você abrir e os dados tiverem mais de 12 horas. O token fica salvo só neste navegador.
